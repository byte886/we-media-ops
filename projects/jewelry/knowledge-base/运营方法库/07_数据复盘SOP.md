# 07 数据复盘SOP —— 发了之后怎么看、怎么改

> 来源：泉泉5张工具表（爆款分析/对标拆解/运营复盘/直播监控/自有账号分析）
> 用法：每次发布填"自有账号分析"，每周日填"运营复盘"，数据驱动选题池迭代。
> 核心：**多数珠宝老板缺的正是作品复盘总结**——复盘不是记流水账，是找"哪个环节影响结果"。

---

## 一、五张表怎么用（优先级排列）

| 表 | 频率 | 干什么 | 看什么指标 |
|---|---|---|---|
| **自有账号分析表**（日常必用） | 每次发布后 | 记录选题/目的/数据 | 曝光、赞藏、评论、涨粉 |
| **运营复盘表**（日常必用） | 每周日 | 单篇+周汇总+结论 | 好/差选题、可复制点 |
| **爆款笔记分析表** | 每周 | 拆解对标爆款 | 标题/文案/封面/数据规律 |
| **对标账号拆解表** | 每两周 | 同行横向对比 | 定位/选题/爆款变化 |
| **直播对标监控表** | 按需 | 评估是否开直播 | GMV/人气/客单价/UV价值 |

## 二、自有账号分析（每篇必填）

| 字段 | 说明 |
|---|---|
| 发布日期 | 便于看发布时间规律 |
| 标题 | 记录改版前后的效果 |
| 文案 | 记录完整版 |
| 选题/内容 | 归类（鉴别/避坑/案例/日常） |
| 目的 | 这篇为什么发（立人设/立专业/引流） |
| 数据 | 曝光/赞藏/评论/涨粉/私信 |
| 备注 | 主观观察+可改进点 |

## 三、周复盘（每周日 30 分钟）

```
① 数据汇总：本周7篇（或N篇）各自曝光/互动
② 找出TOP1和BOTTOM1：为什么？（标题？封面？选题？发布时间？）
③ 结论写回：TOP类选题→03选题池加注"已验证"；BOTTOM类记原因
④ 下周调整：选题方向/发布时间/封面风格各调1-2个变量（一次别全改）
⑤ 记录到 TASK_STATUS / 复盘文档
```

## 四、关键指标解读

| 指标 | 健康信号 | 问题信号 |
|---|---|---|
| 曝光（小眼睛） | 500+稳定增长 | 长期<200：标题/封面问题 |
| 赞藏比 | 赞+藏/曝光 >5% | 低：内容没戳中需求 |
| 收藏/点赞比 | 藏>赞 | 干货强，可引导关注 |
| 评论 | 有实质问题提问 | 只有表情：互动钩子弱 |
| 涨粉 | 每篇有新增 | 0：缺"关注理由" |
| 私信咨询 | 有询价/问真伪 | 无：转化路径没打通 |

## 五、注意事项

- **数据口径统一**：以平台后台为准，每周固定时间记录
- **一次只改一个变量**：改标题就只改标题，别同时换封面+时间，否则不知道是哪个起作用
- **前30天不焦虑**：冷启动期数据差是常态，目标是找到1-2个可跑方向
- **合规红线**：不刷数据、不买粉、不互赞群（封号风险）
