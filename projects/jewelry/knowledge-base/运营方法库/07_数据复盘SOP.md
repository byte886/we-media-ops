# 07 数据复盘SOP —— 发了之后怎么看、怎么改

> 来源：泉泉5张工具表（完整字段已吸收）+ 我们复盘经验
> 用法：每次发布填"自有账号分析"，每周日填"运营复盘"，数据驱动选题池迭代。
> 核心：**多数珠宝老板缺的正是作品复盘总结**——复盘不是记流水账，是找"哪个环节影响结果"。

---

## 一、五张表总览（完整字段）

| 表 | 频率 | 干什么 | 字段见 |
|---|---|---|---|
| **自有账号分析表**（日常必用） | 每次发布后 | 记录选题/目的/数据 | §二 |
| **运营复盘表**（日常必用） | 每周日 | 单篇+周汇总+结论 | §三 |
| **爆款笔记分析表** | 每周 | 拆解对标爆款 | §四 |

## 三、运营复盘表（每周日 30 分钟）

### 板块一：单篇笔记数据

| 字段 | 说明 |
|---|---|
| 发布时间 | 笔记发布时间 |
| 主题 | 笔记主题 |
| 创作内容 | 创作方向与内容 |
| 浏览量 | 曝光数据 |
| 点赞 / 收藏 / 评论 | 互动明细 |
| 涨粉量 | 新增粉丝 |
| 分享数 | 分享次数 |
| 主要观众来源 | 流量来源（推荐/关注/搜索） |

### 板块二：一周数据汇总

| 字段 | 说明 |
|---|---|
| 新增粉丝 | 周涨粉 |
| 主要访客 | 访客特征 |
| 浏览量 | 周总曝光 |
| 浏览时长 | 平均浏览时长 |
| 互动数 | 总互动量 |
| 点赞/收藏/评论 | 互动明细 |
| 分享 | 分享数 |

### 板块三：周总结（核心！）

单独一行记录本周复盘结论与下周优化方向：

```
① 数据汇总：本周N篇各自曝光/互动
② TOP1和BOTTOM1：为什么？（标题？封面？选题？时间？）
③ 结论写回：TOP类选题→03选题池加注"已验证"；BOTTOM类记原因
④ 下周调整：选题/发布时间/封面各调1-2个变量（一次别全改）
⑤ 记录到 TASK_STATUS / 复盘文档
```

| 字段 | 说明 |

## 五、对标账号拆解表（每两周）

**行（拆解维度）**：账号定位（名称/简介/粉丝数/人设定位/账号特色）+ 选题内容（选题方向/内容类型/话题/关键词/笔记数量/更新频率/发布时间）+ 爆款笔记（标题/封面/文案/内容结构）+ 笔记数据（点赞/收藏/评论）

**列**：筛选方向（分组标签）| 拆解项 | 账号1 ~ 账号9（每账号一列）

> 已沉淀账号名单：`运营方法库/06_对标账号库.md`（小红书9+抖音8）

## 六、直播对标监控表（按需，评估直播前启用）

| 字段 | 说明 |
|---|---|
| 账号 | 对标账号 |
| 直播时间 | 日期/时段 |
| GMV | 成交总额 |
| 人气峰值 | 最高在线人数 |
| 客单价 | 平均客单价 |
| 总场观看人数 & UV价值 | 场观与人均价值 |
| 销量 | 成交件数 |
| 直播时长 | 直播时长 |

**用法**：定期记录对标直播数据 → 横向对比转化效率 → 结合客单价与UV价值判断流量质量与变现能力 → **决定我们是否开直播**（冷启动期不做，30-60天阶段评估）。

---

## 七、关键指标解读

| 指标 | 健康信号 | 问题信号 |
|---|---|---|
| 曝光（小眼睛） | 500+稳定增长 | 长期<200：标题/封面问题 |
| 赞藏比 | 赞+藏/曝光 >5% | 低：内容没戳中需求 |
| 收藏/点赞比 | 藏>赞 | 干货强，可引导关注 |
| 评论 | 有实质问题提问 | 只有表情：互动钩子弱 |
| 涨粉 | 每篇有新增 | 0：缺"关注理由" |
| 私信咨询 | 有询价/问真伪 | 无：转化路径没打通 |
| 互动标准 | 1000-2000浏览有50+互动 | 低于：需内容优化 |

---

## 八、注意事项

- **数据口径统一**：以平台后台为准，每周固定时间记录
- **一次只改一个变量**：改标题就只改标题，别同时换封面+时间
- **前30天不焦虑**：冷启动期数据差是常态，目标是找到1-2个可跑方向
- **合规红线**：不刷数据、不买粉、不互赞群（封号风险）
- 工具表模板底稿在泉泉宝典（xlsx重建版），需要可复制使用
