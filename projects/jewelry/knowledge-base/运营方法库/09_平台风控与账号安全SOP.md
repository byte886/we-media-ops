# 09 平台风控与账号安全 SOP

> **文档类型**：SOP（账号出问题/养号/发布安全时的操作流程）
> **适用**：小红书 / 抖音 / 视频号 三平台，发布前与出问题后必查
> **来源**：公众号流量主万字复盘（月入10万实战，2026-10 吸纳）+ 琛盛堂实地踩坑
> **原则**：平台机制（审核/限流/去AI/隔离）跨平台通用，只把公众号特例改写成三平台版本

---

## 一、账号基础设置（第一步就决定生死）

### 头像与名称红线
- ❌ 不用美女头像、不用纯AI生成头像 → 平台图像识别直接打"营销号"标签，初始风控拉高，起号难度翻倍
- ❌ 名称/简介带敏感词、夸大词、引流暗示（微信/电话/二维码暗示）
- ✅ 用**店铺实拍图/货品特写**做头像（我们天然合规：有真实店铺背书）
- ✅ 名称中性稳妥，简介只写"襄阳实体店·翡翠珠宝"，不写任何联系方式

### 改名/改头像频率
- 新号（未入池）：一周内改2次没事
- **已稳定入池：坚决不动**（改了会短暂影响账号标签）
- 频繁改昵称/简介 = 营销号特征，已写入合规检查清单

## 二、账号"去留"决策（别瞎注销）

### 建议注销的情况
1. 历史爆文掉池：出过几千上万阅读，现在持续个位数、无推荐来源
2. 用过流量券/助推后流量崩盘（已被深度标记）
3. 主体失效：执照注销、服务号不适合做流量
4. 被官方正式处罚、流量归零
5. 连续多天所有内容0推荐，各种恢复方法都试过

### 别急着注销的情况
1. 老号刚恢复更新暂时没流量 → 稳定更新5-7天观察
2. 只发过图文没发过正式视频 → 不能据此判断，转赛道内容测试
3. 单纯想换赛道 → 直接发新内容，不用删旧文、不用注销
4. 少量违规删文但整体有推荐 → 单篇不影响整号
5. 新号第1篇流量好、后面掉到个位数 → 正常波动，不是限流

### 频繁注销的严重后果（必看）
- 平台记录**设备ID+IP指纹**：同一设备/IP 3-5天内注销2次以上 → 被判"工作室批量废号"，进隐性黑名单
- 进黑名单后：该设备/IP 上注册的新号**永远拿不到流量**
- **洗稿+频繁注销 = 平台识别废号的最强信号**
- 安全做法：注销和注册新号**换设备、换网络**；单个号偶尔注销没事，别短时间反复

## 三、多账号运营与隔离（IP 污染是隐形杀手）

### 一机一卡一号怎么执行
| 账号数 | 做法 |
|---|---|
| 2-3个号 | 可共用一台手机，但**必须不同赛道**；发文用各自手机流量，不连同一个WiFi |
| 3个以上 | 严格一机一卡一号，独立手机+电话卡+流量 |
| 5个以内轻量 | 电脑统一排版做素材存草稿，**发布时**分别用对应手机+手机流量 |

- **关键认知**：登录排版不会触发关联，**发布时的网络独立**才是核心。同一台电脑登录多个号排版完全没问题。

### IP 污染判断与解决
- **什么是IP污染**：同一个公网IP下有账号做过违规/批量发文/频繁注销 → 该IP被打"高风险"标签，其下所有号受牵连（0曝光、不起量）
- ❌ **绝对不用公司WiFi/商场/咖啡厅/共享WiFi发文**——你无法控制同网络下别人做过什么
- 判断方法：内容合规+操作正确，连续7天0曝光且IP固定不变 → 90%是IP污染；换设备换网络发一篇测试内容验证
- 解决办法：
  - 短期：手机开关飞行模式/重插SIM卡，运营商重新分配IP
  - 长期：独立随身WiFi（约29元设备+9.9元/月），一号一网
- 查自己公网IP：ip138.com / iping.cc

### 矩阵不翻车原则
- 先跑通1-2个号验证赛道，再扩规模；别一上来铺十几个号
- 轻量矩阵（5-15个）：浏览器指纹隔离（比特浏览器类），赛道必须错开
- **2025年9月后新风险**：平台开始检测**写作方法和文风统一度**——所有号同一套提示词/模板/文风 = 工作室特征，批量限流
  - 应对：每个号用不同AI模型、不同提示词风格、不同选题角度，刻意做差异化

## 四、系统误判（你没做错也可能没流量）

- 所有内容平台算法普遍存在 **15%-20% 误判概率**（漏判放垃圾、错杀优质内容）
- 单平台单账号 ≈ 20%概率踩坑被误判限流，纠正需4-6个月持续合规更新，多数人熬不到
- **解决方案：至少2个账号 + 至少2个平台**，用数量对冲误判风险——这也是我们做"小红书+抖音+视频号"三平台的底层理由之一

## 五、发布规范与频率（细节决定赚还是废）

### 发文间隔与数量
- 同一账号一天多篇：**每篇间隔1小时以上**；短时间连续大量发布 = 机器批量特征
- 单账号每天**不超过6篇**；养号期/起号期**一天1篇足够**；稳定期1-2篇健康
- 不是发的越多赚的越多，账号状态和内容质量远重要于数量

### 定时发布（重点警告）
- **新号、起号期绝对不用定时发布**：定时发布的内容会提前进入系统做前置质量审核和灰度测试，等于多一轮前置筛选，新号内容竞争力弱 → 基本死在冷启动
- 在哪里设置定时就算在哪里发布：电脑端定时=电脑发布，**不享受手机发布的权重加成**
- 标准操作：**电脑端排版做素材存草稿，手机端连手机流量发布**（小红书/抖音/视频号通用）

### 四大高危功能（新号起号期全部禁用）
合集/定时/定位/助推 —— 使用即触发深度检测，审核标准更严，查出问题扣分
- 新号起号期全部禁用，账号稳定后再按需使用
- 助推/流量激励：**十个用九个废**，新号绝对不用；只在账号稳定+内容100%合规+已是爆款时谨慎使用

## 六、限流判断与恢复（全文最值钱的部分）

### 怎么判断限流了
- 核心指标：**曝光量持续低于50且连续多篇** → 基本判定限流（阅读低可能是标题差，曝光低一定是系统不给推）
- 辅助验证：内容数据页看"数据来源"，完全没有"推荐"来源 = 限流
- IP/设备污染判断：连续7天全0曝光+IP固定不变 → 换设备换网络发一篇测试验证

### 限流的12种常见原因（对照自查）
1. 新号日更（被判定工作室批量号）——新人最常踩
2. IP/设备污染（公共网络、被标记设备）
3. 内容违规/疑似违规（明显违规有通知，疑似违规默默限流——**大部分暗限流是疑似违规**）
4. 频繁注销注册
5. 内容同质化严重（抄别人或自我重复，一篇扣20分；**图片同质化也严查**：配图风格单一、大量重复AI图、搬运网图）
6. AI内容占比过高（**全账号AI占比超35%会被打标**，打标后推荐权重受影响）
7. 72小时内大量转发群/朋友圈（判定人工干预数据）
8. 历史文章秋后算账（半个月前的文章被深度检测查出 → 整号降权）
9. 使用高危功能（合集/定时/定位/助推）
10. 自我同质化（连续几篇话题/标题/结构高度相似）
11. 低质量创作过多（完读率/完读时长不达标 → 低质量标签 → 推荐砍半以上）
12. 大量截图/整合内容（评论截图拼接 = 整合类垃圾内容）

### 限流后怎么恢复
- **核心方法一：图文+视频交叉发布**。限流严重先停发视频，只发图文/小绿书类低风险内容，用低同质化内容把账号分拉回来
- **核心方法二：删违规+申诉**。删完违规/低创作内容，日更合规内容，去账号反馈整体申诉，**话术里一定要加"请求人工审核"**（触发人工审核，否则只有机器审）
- **核心方法三：持续更新恢复**。连续20天合规更新，每天约加2分
- **误区：停更"休克疗法"已完全没用**，停更不会恢复分数，反而让权重更低。必须坚持更新用合规内容把分挣回来
- 辅助手段：
  - 删除历史违规/低质量旧文，减少负面扣分
  - 分数没低于80可换题材/换赛道，恢复立竿见影，比重生快
- 恢复周期参考：轻度限流1-2周；中度1-3个月；重度/黑名单基本救不回，注销重开

## 七、审核系统认知（理解了就不焦虑）

### 两套账号机制
- **天选号（约20%）**：新号注册自带流量buff，起步就有曝光 → 别人新号爆不代表你方法错
- **考核号（约80%）**：需要1-3个月合规试用期，平稳度过才稳定给流量 → 前3个月核心目标就一个：**不显性违规、不疑似违规，平稳度过试用期**

### 三套审核系统（为什么"发的时候好好的，两周后突然限流"）
| 层 | 时机 | 查什么 |
|---|---|---|
| 普通检测 | 发文时即时 | 明显违规词/敏感词/色情暴力等硬违规 |
| 深度检测 | 滞后抽检，约两周后批量 | 同质化、AI痕迹、隐性违规、软广告 → **这就是两周后突然限流的原因** |
| 人工抽检 | 高流量内容（爆文）必进 | 5万+阅读是坎 |

- **为什么违规提示不准**：平台绝不告诉你真实原因（怕被逆向研究），常见提示"行文生硬/啰嗦/注水"90%真实原因是题材敏感、踩隐性红线
- **应对**：不要纠结提示里的理由去改文笔，**去检查题材、选题、敏感点，从内容方向找问题**

## 八、AI 痕迹与去AI化（直接决定能不能持续）

### AI工具选择原则（重要认知）
- **写作AI和发布平台要错开**：不用同一家公司的AI写同一家平台的内容（训练数据里自家平台内容占比高，容易撞车同质化）
  - 公众号内容优先用豆包/Kimi（非腾讯系）
  - 头条系内容优先用元宝/Kimi（非字节系）
  - **映射到我们**：小红书/抖音是字节系平台 → 内容生成避免纯用字节系AI，或生成后必须深度二次改写
- 跨平台分发：同一内容发多个平台**必须用不同AI模型分别重写**，不能原文搬运
- 通用最优：Claude / Gemini / GPT 跨平台都相对安全

### AI占比红线
- **单篇AI内容不限流，全账号AI生成内容占比超35%会被打标**，打标后推荐权重受影响
- 不用过度焦虑检测工具数值，没被打标就不用死磕；内容质量和选题才是核心

### 去AI痕迹实操（三招）
1. **拆句法**：AI爱写超长复合句（一句话一两百字、逻辑嵌套多）→ 全部拆成短句，一句拆2-3句，句号断开，去掉"综上所述/由此可见/值得一提的是"等AI高频套话
2. **口语化改写**：人工通读全文，把不符合自己说话习惯的地方全改成平时会说的话；**开头和结尾重点改**（AI特征最明显，也是检测重点区域）
3. **工具法**：可用AI降痕工具辅助（辅助，主力仍是人工改写）

## 九、图片使用安全（小红书隐形水印是重灾区）

### 小红书图片隐形水印（必知）
- 小红书图片除可见官方水印外，**还有10多个隐形水印**嵌在像素里，肉眼不可见但算法可读，能追溯到原始来源和发布者
- 普通去水印/裁剪/加滤镜去不掉隐形水印；**直接搬运小红书图发其他平台 = 搬运非原创，必被检测**
- ✅ 正确处理：深度二次创作——主体抠出、换新背景、加文字贴纸滤镜、重新导出改变像素结构
- ✅ 我们的天然优势：**店铺实拍+AI生成图**，不存在搬运风险；但AI生成图也要按标准流程处理

### AI生成图处理流程
- 不能直接发纯AI图（系统有专门的AI图识别模型，大量直接发会被判低质量AI素材）
- 标准流程：AI生成（纯白背景、主体清晰）→ 抠出主体 → 放新背景画布 → 加文案/装饰 → 调整色调质感锐度重新导出
- AI自带水印必须裁掉；整篇配图风格统一；**图片上的文字会被OCR识别合并计算原创度**（图片文案也要原创）

## 十、赛道与选题红线（对我们珠宝的映射）

### 绝对不能碰的赛道（通用）
医疗养生治病类、财经股票类、时政民生敏感类、敏感国际话题、体育赛事新闻（版权）、星座生肖（迷信）、国内名人（肖像名誉权）

### 珠宝线映射
- ✅ 我们做：翡翠知识/选购避坑/真假鉴别/门店日常/客户故事
- ❌ 不碰：赌石切石、治病养生功效（已有合规清单）、投资升值承诺（已有合规清单）、借用名人肖像
- 赛道"垂直"的底层逻辑：**垂直于某一类用户，不是垂直某一个领域**——锁定人群持续需求（珠宝选购人群的痛点、疑问、日常困惑），选题可跨领域扩展（翡翠+玉镯佩戴+送礼+辨假+保养），同一批用户，选题不枯竭

### 标题红线（平台严查）
- ❌ 情绪词：炸裂、天塌了、出事了、紧急、重磅、震惊
- ❌ AI敏感词：AI写作、ChatGPT、Claude、GPU、算力、大模型
- 起号期用平淡标题最安全，稳定后再优化点击率
- **映射**：我们选题池里"震惊+反转"类标题要检查是否踩情绪词红线

## 十一、其他高频踩坑（对照自查清单）

| 坑 | 说明 | 我们的做法 |
|---|---|---|
| 头像雷区 | 美女头像/纯AI头像 → 营销号标签 | 店铺实拍/货品特写 |
| 删文频率 | 一天最多删1-2篇，一口气删几十篇触发异常 | 已写入合规清单 |
| 英文标点 | 大量英文标点误判AI生成 | 统一中文标点 |
| 外链水印 | 图片带其他平台水印 → 降权 | 只发自己实拍/AI图 |
| 转发刷量 | 冷启动期72小时内大量转群/朋友圈干扰算法 | 发布后自然转发即可 |
| 跨平台引流 | 正文留联系方式有风险 | 走主页置顶指引 |
| 删文重发 | 高流量文章删掉重发会被检测不再给流量 | 不删爆文重发 |

## 速查：账号出问题先走哪步

1. 先判断是不是真限流（曝光<50 + 连续多篇 + 无推荐来源）
2. 对照12种原因自查（尤其：IP污染？定时发布？助推？同质化？AI占比？）
3. 是IP污染 → 换网络发测试文验证 → 飞行模式换IP / 独立WiFi
4. 是内容问题 → 删违规旧文 + 日更合规内容 + 申诉（话术加"请求人工审核"）
5. 坚持更新20天恢复分数，**不要停更**
6. 确认救不回再考虑注销，注销前换设备换网络
