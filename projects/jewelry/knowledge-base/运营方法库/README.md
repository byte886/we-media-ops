## 使用规则

1. **素材 vs 用法分离**：泉泉宝典是"别人给的资料"，本目录是"我们怎么用"；改用法不改素材。
2. **所有标题/话术必须二次改写**：只借结构，内容必须是我们自己的（原创+合规要求）。
3. **执行优先级**：档位1（选题→脚本→合规→AI味检查）每次发布都走；档位2（复盘表）每周走。
4. **更新机制**：每周复盘后，把"跑得动/跑不动"的选题写回 03 选题池；对标变化写回 06。
5. **决策留痕**：赛道取舍/后置项（投放/企业号/直播）的完整方法论与决策依据见 ADR-006，不在本目录重复写理由。
