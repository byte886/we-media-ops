## 0. 决策结论：朋友圈"一篇发完"还是"系列连载"

**结论：连载，不一篇发完。共7条，隔天1条摊两周，10-05（周一）发第一条；不卡点，睡前或午休随手发。**

用户倾向连载，下面把理由说死：

1. **内容量根本装不进一条。** 这篇长文是8个章节 + 9条提醒 + 6条行动清单，外加7个圈友复盘案例。一条朋友圈就算写满，也只能讲一个点。硬塞成"一篇发完"，等于把一篇公众号长文压缩进朋友圈，谁都读不完。
2. **折叠机制直接判死刑。** 朋友圈正文超过约6行就折叠成"全文"，多一次点击≈90%流失。一篇发完，意味着逼着所有好友都得点一下"全文"——而调研样本里反复验证：折叠一次，掉九成。
3. **注意力节奏不对。** 朋友圈是碎片刷屏，没人在朋友圈里读长文。连载是"每天喂一口"，符合刷圈节奏；一篇发完是"端上一桌"，人直接走了。
4. **转化节奏靠养，不靠一发入魂。** 连载=连续剧，每条末尾留钩子勾下一条；信任是7天逐日累积的，不是一条爆文建立的。"边学边干的实践者"这个人设，天然就适合连载——"我读了篇长文，这几天拆成几条发出来理思路"，比"我来给大家总结一篇雄文"真实得多。
5. **一篇发完该去的地方是公众号/长文，不是朋友圈。** 朋友圈只负责抛判断、秀案例、埋钩子，深度引导私信。

> 一句话：**朋友圈连载养信任，小红书/抖音捞新人，长文留给公众号。** 本手册只做前两个半。

## 1. 内容母稿（核心观点库）——这就是"鱼"

把长文+飞书案例消化成9条可被三平台反复投影的洞察。每条：洞察一句话 + 支撑数字（标【OCR】=亦仁原文 / 【飞书】=圈友复盘合集）+ 可用的个人判断角度。

### 洞察1：行业AI工作台 = 把"一件具体小事"封装成拎包入住的产品，不是做大而全的SaaS平台
- **数字**：生财站内搜"工作台"，今年5月约7条 → 8月约51条 → 9月约46条【OCR】；做得最清楚的人都只做一件事——晓海云创只做主图详情页、嘟嘟MD只做"一段文案进→剪映草稿出"、芸光只做"让AI推荐你"【OCR】。
- **个人角度**：看完一个反直觉的点——越小越好交付、越好验收、越好定价。以前总觉得产品要大而全，这几个案例转过弯了。

### 洞察2："看得见"比"能力强"更重要——工作台是给客户看的样品
- **数字**：袁欣做CEO外脑，客户总在问"你给我的到底是什么"，于是挑一条具体业务做成看得见的工作台，客单2-5万、多数29800元，5个多月做16家企业累计营收超50万，客户基本全靠转介绍，她连这个产品的朋友圈都没发过【OCR】【飞书】；亦仁原话"如果我自己不会搭，有人搭好了展示给我看，100万我也会买"【OCR】。
- **个人角度**：我以前也觉得"我自己用Codex/Claude Code就够了"。但吸引客户，必须有一个能截图、能演示、五分钟看懂的页面。能力是后台，样品是前台。

### 洞察3：真正的钱在"不会用、有需求、付得起"的900人身上，不在卖token差价
- **数字**：开放日上亦仁直接说"卖token是非常差的商业模式"——1000个客户里100个聪明、会用、但不付高价；另外900个不会用、有需求、可能愿花几万让你帮他全部搞定【OCR】；收到高价的都是这么收：袁欣29800元/单、芸光从第一单880元/月做到最贵3万/月【OCR】【飞书】。
- **个人角度**：看完算明白了——低价工具只能筛出会用的人。该设计一个几万块的"帮你跑通"标准品，而不是每个咨询都单独定制（那是体力活）。

### 洞察4：现在搭得起了——开发成本和门槛都塌到地板，企业渗透率却只有18%
- **数字**：晓海云创出图网站14天开发（7天开发+7天完善）、前期花费不到1000元【OCR】【飞书】；袁欣这套方法一行代码都没有【OCR】；一个朋友复刻一个复杂广告素材工作台，一晚上做到八成【OCR】；IDC今年5月调研：智能体在中国企业业务里渗透率只有18%【OCR】；Anthropic拿1亿美元，要在2027年底前培训1万名驻场工程师，官方说法"能让AI在真实业务里跑起来的人，最难招"【OCR】。
- **个人角度**：渗透率18% = 十家企业八家还没真下手。这是空窗期，但窗口是给"先动手"的人，不是给"准备好"的人。我边学边干，正好。

### 洞察5：封装得越彻底、客户越不用动脑，才越留得住——"没玩明白"是最大杀手
- **数字**：深小白早期只给客户一个智能体框架，客户用不起来；4-6月把场景逐个做成现成技能后，6月底开卖、7月成交100多单【OCR】【飞书】；但到9月，月卡续费率约20%（OCR写"不到三成"，系现场转述与原文两处口径，引用时以"约20%"为准并保留双注），回访客户说得最多的一句是"产品不错，但没玩明白"【OCR】【飞书】。
- **个人角度**：这个数挺扎眼——卖出去100多单，续费才两成。说明工具卖出去只是开始，技能封装+培训+陪跑才是复购，光把工具扔出去是不够的。

### 洞察6：别押在一个接口上，也别卡在"收工具钱、干服务活"的中间态
- **数字**：西瓜苗跨境视频工作流全靠一个视频模型第三方接口，今年1月接口被风控，两个月里月收入从3-5万掉到1-2万【OCR】；西瓜苗复盘原话"我们收的是工具的钱，但交付的是服务的活"【OCR】；秀才哥伦布光SimilarWeb接口一个月就900多美元，他自己都劝别人别照抄【飞书】。
- **个人角度**：单一依赖=随时归零。做工具的人，接口成本和稳定性必须算进模型里。要么彻底做工具，要么彻底做服务，中间态最累。

### 洞察7：工作台本身没有壁垒，壁垒在人——行业经验、IP、客户信任
- **数字**：卧龙先生给老师做的班级管理工具卖火后，冒出一批名称、界面都照搬的版本【OCR，惠州沙龙复盘】；小红书帮人搭个人工作台，有人标价19.9元一次【OCR】；晓海云创遭遇价格战——"美图设计室不到1元一张，还有人卖2-3毛一张"【飞书】。
- **个人角度**：复制成本极低，所以对行业的理解、持续输出把人立住的内容，才是抄不走的东西。这也是为什么要做内容矩阵，而不是只做工具。

### 洞察8：终局是"交付结果"收费，不是交付软件收费
- **数字**：金蝶今年上半年AI原生产品收入同比增长189%【OCR】；用友上半年AI相关合同签了9.06亿，推驻场工程师按结果收费【OCR】；芸光和客户约三个指标（提及率、首推率、中正率），签约带三个月考察期、做不出来客户无责走人，过了考察期指标没完成按约定扣钱，但说清楚"这不是保证排名"【OCR】【飞书】；a16z研究垂直软件：客户付的不只是软件费，还有原来的人工费【OCR】。
- **个人角度**：从卖软件 → 卖工作台样品 → 卖定制 → 卖结果，客单一路往上走。敢不敢承诺结果，是分水岭。

### 洞察9：从哪开始——先给自己搭一个，第一版减到不能再减
- **数字**：袁欣、嘟嘟MD、秀才都是先自己用跑通，身边人才来问【OCR】；秀才之前5个月做了20多个工具站、真正上订阅的七八个，哥伦布8月4日上线第1天0单、第2天2单、第3天3单【飞书】；亦仁"产品第一版要减到极致，一个最简单功能点上线推给用户，没反应说明点不对，再调"【OCR】。
- **个人角度**：试错密度极高，20多个工具站才跑通一个。我不赌一发命中，快速出最小版本扔出去看反应。

> **口径提醒（写文案时别踩）**：嘟嘟MD"订阅3万+"累计还是单月，原帖两处不一致——**本手册全部成稿一律不写这个数字**；李可美业那20+家是"预约"不是"已付"，作者本人强调不能混——**本手册成稿一律不引李可案例**；晓海云创"4.5个月10万+"与"13万左右"是帖内两处写法，本手册统一用"10万多"。

## 2. 三平台共用写作SOP（长期复用，以后任何长文都能套）

这一节是母流程，以后读完任何一篇别人的长文，都照这7步拆。

### 2.1 怎么把别人长文拆成自己的观点
1. 第一遍通读，拿笔标"扎眼数字"——凡是带具体数字的句子，全划出来。
2. 第二遍只看数字，问自己一句：**"这个数跟我做的事、跟我认识的商家，有什么关系？"** 没关系的数字，丢掉。
3. 每个留下的数字，逼自己写一句"我的判断"——不允许写"亦仁说得对"，要写"我注意到……""我算了笔账……""我打算……"。
4. 一篇长文拆出8-10条这种"数字+我的判断"，就是母稿（见第1节）。

### 2.2 怎么选钩子
- **数字钩子最狠**：29800元、14天/1000元、渗透率18%、续费20%、收入从三五万掉到一两万。
- **反常识钩子**：卖token是差生意；小比大好；不写代码能收29800；卖出100单续费才两成。
- **身份钩子**：做电商的我告诉你……；做AI工具站踩过坑的人说句实话。
- **禁用开头**：大家好 / 今天分享 / 我来教你 / 众所周知 / 最近读了一篇好文（太空）。

### 2.3 怎么用"我/我们/我注意到"替代转述腔
- 不写"亦仁在文章里提到""文章指出"，改写"我看到一个数据挺扎眼""开放日上有人算过一笔账""圈友里有个做XX的"。
- 引用别人的案例时，转成第一人称视角："我注意到，一个做电商出图的圈友……"——重点是"我注意到"，不是"某某某说"。
- 允许说"我读到这个挺有共鸣""我打算试试"——边学边做人设靠这种句子立住，**不**靠"我很专业""我做过/我踩过"。

### 2.4 怎么埋个人判断
- 每条内容至少一句"我的判断是/我不这么看/我觉得"。
- 调研结论：**偏见才是最值钱的资产**。不写"有人认为A也有人认为B"，要敢站队。
- 适当"赶走"一部分人：比如"这个不适合想躺赚的人"，排斥反而制造归属感。

### 2.5 长短句节奏
- 短句为主，长句不超过一行（手机屏幕一行≈18-22字）。
- 像说话不像念稿：该停顿就换行，该用逗号就别用长定语。
- 一段别超过3句，朋友圈段落更短。

### 2.6 配图设计SOP（基于2025-2026跨平台调研）
**总原则：图是用来停住刷的手的，不是装饰。**

**朋友圈：**
- 张数：1张效果最好（完整展开不裁剪），其次2/3/4/6/9张；不要5/7/8张（视觉不平衡）。
- 缩略识别：朋友圈信息流里图很小，最重要的元素（一个数字/一句钩子）必须居中放大，缩小到指甲盖也能认出。
- 风格：黑底白字极简卡可用，但纯文字卡发多了像营销号——**7条里最多3条用黑底卡，其余配真实场景图**（桌面/笔记本/咖啡/工具截图）。
- 人脸有38%更多互动：有机会露个手/杯子/侧脸，比纯卡片有温度。
- 文字≤6行，超过折叠。

**小红书（和朋友圈逻辑相反）：**
- 比例：3:4竖版（1080×1440），不要1:1，不要横图。
- 色调：**避免大面积灰黑**（调研明确指出），用明亮清爽的底色（米白/浅黄/淡蓝）+ 深色粗字。
- 主标题≤6字，放画面中央，字号占画面1/3；副标题补关键词。
- 留白60-70%，主体突出，不要堆信息。
- 情绪：封面要让人产生"我也想做到/这说的就是我"的感觉，不是冷冰冰的数据卡。
- 8种高点击模板：合集封面/对比封面/留白封面/数字封面/深色封面/钩子封面/破坏封面/真人出镜。知识类优先用"数字封面"或"钩子封面"。

**抖音：**
- 前2秒跳出率>50%就必须重做封面和开头。
- 封面=一行大字+一个表情/动作，一眼看到冲突或悬念，不要说明书式排版。
- 前3秒画面必须有视觉冲击：举纸怼镜头（写着关键数字）、特写（手画的图/屏幕录制）、人物表情。
- 高密度视觉信息（特写/对比色/大字）能降68%跳出率。
- 9:16竖版，高对比色，单焦点。

### 2.7 评论区自留地玩法
- 正文克制（朋友圈≤6行），长内容/链接/价格/完整清单，放评论区第一条。
- 发完30分钟内（小红书/抖音1小时内）回复所有评论，拉权重。
- 引导5字以上深度评论："你平时用AI解决什么问题？评论区说，我出专属拆解。"
- 小号在评论区补补充信息/群入口，避免主号限流。

## 3. 朋友圈平台

### 3.1 朋友圈专属SOP
- **正文铁律**：≤6行，分2段，中间空行。超过就折叠，掉90%。
- **每条只选一个行动目标**：要么预告连载、要么抛判断、要么求评论，别一条里又预告又卖货又求关注。
- **钩子第一句说人话**：事件开头（我最近在琢磨）/数字开头（一个客单29800的生意）/冲突开头。
- **多发"人的故事"，少发"产品的故事"**：把判断嵌进"我读到、我算过、我打算试试"里，不要写"我做过、我踩过"。
- **生活/干货/产品≈4:3:3穿插**，产品内容不连发两天；本手册这7条全是干货，发布时中间要穿插1-2条日常碎碎念中和。
- **时间**：早通勤7:30-8:30发短感悟，午休12:30发中等干货，睡前21:30发互动率最高的内容。

## 5. 抖音平台

### 5.1 抖音专属SOP
- **前3秒定生死**：第一句必须制造认知缺口（"他说的这个我知道一半，另一半不知道"）。钩子六类：痛点/反常识/数字/反差/身份/故事开端。
- **禁用开头**：大家好 / 今天分享 / 我来教你——观众只关心"这条和我有什么关系"。
- **口播结构**：钩子(0-5s) → 三点(认知→方法→行动) → 收尾(种关注期待"下条讲……")。
- **节奏**：30秒≈7-10个镜头、单镜3-4秒；台词≤15字一句，像说话不像念稿。
- **画面比台词重要**：讲数字就举纸怼镜头，讲工具就录屏幕，讲对比就前后切换；别站着干说。
- **花字**：关键词放大、变色、弹跳；金句单独打屏。
- **合集连载**：同一主题拆成合集，每条末尾引导看下一条；连续发同类型打标签；第一组4条跟着朋友圈两周节奏走，**不必卡点固定时段**，拍完剪好就发。

### 7.1 朋友圈：查"像不像真人随手发的"

- [ ] 标题是否≤20字、前10字有核心关键词？

- [ ] 标题是不是承诺了一个具体结果/数字，还是空喊"干货""必看"？

- [ ] 结尾有没有低成本CTA（评论区/收藏），还是硬广？

- [ ] 整条是不是30-40秒、镜头有变化，还是一镜到底念稿？

- [ ] 有没有"首先/其次/总而言之/综上所述/值得一提的是"？
- [ ] 有没有排比三连（"不仅……而且……更……"、"赋能/助力/打造闭环"）？
- [ ] 有没有正确的废话（"AI是未来""要拥抱变化""细节决定成败"）？

## 9. 质检报告（去AI味质检官 · 2026-10-05 过检）

> 本章三件事：①把"去AI味质检官"沉淀成一个以后可复用的角色；②逐条脚本的过检记录（检出问题→改了什么，关键条给改前/改后对照）；③数字核对结论（每个成稿数字的底稿出处）。

### 9.1 可复用角色定义：去AI味质检官（以后写完任何稿子照此自查）

**你是谁**：一个挑剔、不说好话的编辑。你的KPI不是夸作者，是把"AI写的正确话"改回"这个真人会说的话"。你不客套，不写"整体不错"，只挑刺、动手改、留对照。

**你拿的这把尺子**（作者画像）：有思考、会执行、要结果，边学边分享的积极派，做AI/电商方向，生财圈友，不是大佬。他说话该有"我注意到/我算了笔账/这个数挺扎眼/我打算试试，做完来报数据"，该有语气词和小毛病，敢亮个人判断，看到数字会条件反射想背后的逻辑。他不像行业分析师，也不像大学教授；**他没真做过工作台，所以不能写"我做过/我踩过/我来教你"，只能写"我读完打算试试，做完汇报结果"。**

**过稿顺序（逐条脚本，一条都别跳）**：

1. **先扫AI味禁词**："首先/其次/总而言之/综上所述/值得一提的是/不仅而且更"。出现一个圈一个。
2. **扫排比三连**：凡是三句字数差不多、结构一模一样、还都四字短语收尾的（"好交付/好验收/好定价"、"✅…✅…✅…"），打散，改成长短不一的人话。
3. **扫正确的废话**："AI是未来""拥抱变化""细节决定成败"——删。
4. **扫情绪恒温**：全篇没有一句带态度、带语气词、带"我打算…/我读到…"的，就是AI在播音。补一句有立场的判断。
5. **扫对仗金句癖**："看不见的本事卖不上价，看得见的样品才好收钱"这种上下句严丝合缝的，通常是AI在炫技。拆松，留口语，别为了押韵牺牲真实。
6. **扫书面腔**：能说"扒出来喂给AI"就别说"提取出来做成AI能用的东西"；能说"真塌到地板了"就别说"开发门槛显著降低"。
7. **分平台加查**：
   - 朋友圈：>6行、超2段、太整齐太完美 = 营销号味。钩子第一句能不能让人停下来？
   - 小红书：标题党但不假大空？封面≤8字带数字/痛点/身份？正文像真人分享还是像总结报告？
   - 抖音：前3秒逐字稿能不能留人？口播是不是≤15字短句？分镜能不能直接照拍？
8. **最后一道：数字回查**。每个数字都回底稿对口径。底稿没有的数字不许出现在成稿里；口径存疑的（累计vs单月、预约vs已付）宁可不说，不许写死。

**准出线**：改完自己读一遍——如果读着还是像AI写的播音稿，继续改，不许凑数。
