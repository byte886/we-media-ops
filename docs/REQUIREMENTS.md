# 需求与验收标准（REQUIREMENTS）

> **文档类型**：Governance（需求定义）
> **创建**：2026-10-08
> **状态**：珠宝冷启动阶段

---

## 一、业务背景

- 襄阳两家实体店（翡翠、宝石、手镯为主），营业执照：湖北琛盛堂文化传媒有限责任公司
- 操作者帮朋友（店主）做宣传，不想出镜
- 店主愿意出镜但没时间
- 已有供应商产品素材（蓝宝石戒指等样品视频）
- 已有微信私域老客户

## 二、明确不做的

- ❌ 不开在线购物平台/抖音小店
- ❌ 不投流（前30天）
- ❌ 不买赞买收藏
- ❌ 不留微信号/二维码在公域内容里
- ❌ 不发赌石/切石视频
- ❌ 象牙雕刻不进公域（私藏品）
- ❌ 文玩核桃不进公域
- ❌ 不做AI数字人口播
- ❌ 不做纯AI生成假产品图

## 三、验收标准

### 内容质量验收
- [ ] 每篇脚本过AI味检查SOP
- [ ] 每篇脚本过合规检查
- [ ] 每个平台有具体参考对象（哪条笔记/视频，什么标题）
- [ ] 标题从200个爆款标题中参考改写，不是凭空写

### 发布验收
- [ ] D1-D7每天三平台内容完整（标题、脚本、封面、标签、素材清单）
- [ ] 每条内容标注了参考对象
- [ ] 拍摄清单明确（拍什么、几个镜头、给哪个平台用）

### 账号安全验收
- [ ] 一机一号，手机流量发布
- [ ] 新号养号2-3天后再发
- [ ] 不触发任何平台警告

## 四、成功指标（前30天）

| 指标 | 目标 |
|------|------|
| 发布数量 | 小红书20篇+，视频号15条，抖音10条 |
| 单篇最低浏览 | 100+（低于2位数要查限流） |
| 收藏率 | >3%为合格，>5%追投 |
| 私信咨询 | 每月10-30个 |
| 加微信 | 前30天不追求，先做内容 |
